# Spec Delta

## Purpose

会议库只读访问定义 Android 应用如何发现、解析并展示既有的会议数据。它保证与桌面版产出的目录格式双向兼容：在手机上打开电脑录的会议无需任何转换，且手机绝不擅自改写桌面产生的文件。

## ADDED Requirements

### Requirement: 会议目录发现

应用 SHALL 以「根目录下的子目录」为会议单位进行发现，并按会议时间倒序排列。无法确定时间的目录 MUST 排在末尾且仍然可见。发现过程 MUST NOT 修改任何文件。

#### Scenario: 按时间倒序排列

- **WHEN** 根目录下存在三个会议目录，其时间分别为 2026-01-02、2026-03-05、2026-02-01
- **THEN** 列表按 2026-03-05、2026-02-01、2026-01-02 的顺序展示

#### Scenario: 只读发现

- **WHEN** 完成一次完整的会议库扫描
- **THEN** 扫描前后各文件的修改时间与内容哈希保持不变

### Requirement: 会议元数据容错解析

应用 SHALL 从会议目录的 `meta.json` 读取标题、标签与归档状态。当 `meta.json` 缺失或字段缺失时，应用 MUST 以目录名推导标题、以空标签与未归档为默认值继续展示，不得因此隐藏该会议。

#### Scenario: 缺少 meta.json

- **WHEN** 某会议目录不含 `meta.json`，但含转写或纪要文件
- **THEN** 该会议仍出现在列表中，标题取自目录名

#### Scenario: 字段缺失走默认值

- **WHEN** `meta.json` 只包含标题字段
- **THEN** 该会议标签为空且归档状态为未归档

### Requirement: 转写文本解析

应用 SHALL 解析 `transcript.json` 并展示说话人、起止时间与文本内容。相同说话人的连续发言 MUST 在展示上合并为一段但仍保留各自时间戳；说话人别名 MUST 优先于编号显示。

#### Scenario: 展示说话人别名

- **WHEN** 转写数据中说话人 1 的别名为「张伟」
- **THEN** 界面显示「张伟」而非「说话人 1」

#### Scenario: 编号说话人回退显示

- **WHEN** 转写数据中说话人 2 没有设置别名
- **THEN** 界面显示说话人编号对应的默认文案

#### Scenario: 时间戳可定位

- **WHEN** 用户点击转写中的某一句
- **THEN** 界面定位到该句起始毫秒对应的播放位置

### Requirement: 纪要解析

应用 SHALL 识别纪要 Markdown 中的固定章节（一句话总结、议题与讨论、决议、待办、待定问题与风险、原因分析），并在原因分析中的 `fishbone` 代码块存在时 MUST 将其交给鱼骨图渲染，而不是作为纯文本展示。

#### Scenario: 章节化展示

- **WHEN** 打开一份含一句话总结与决议章节的纪要
- **THEN** 两个章节分别以独立区块展示

#### Scenario: 鱼骨图区块被识别

- **WHEN** 纪要包含 ```fishbone 代码块且内容为合法鱼骨图 JSON
- **THEN** 界面展示鱼骨图视图，并同时提供查看原始文本的入口

#### Scenario: 非法鱼骨图不中断展示

- **WHEN** 纪要中的 ```fishbone 代码块内容不是合法 JSON
- **THEN** 其余章节正常展示，该区块以纯文本呈现并标注解析失败

### Requirement: 桌面格式兼容

应用 SHALL 能直接读取桌面端 v0.5.2 产出的会议目录结构，包括 `录音.m4a`、`转写.md`、`transcript.json`、`纪要.md`、`meta.json` 与 `minutes-history/`。缺少可选文件 MUST 视为该功能未生成，而不是数据损坏。

#### Scenario: 打开桌面产出的会议

- **WHEN** 把桌面版导出的会议目录整体放入根目录后重新扫描
- **THEN** 该会议出现在列表中，转写与纪要均可正常查看

#### Scenario: 缺少录音文件

- **WHEN** 会议目录缺少 `录音.m4a` 但含转写与纪要
- **THEN** 界面隐藏播放控件，转写与纪要仍正常展示

### Requirement: 不可读目录隔离

当单个会议目录解析失败时，应用 MUST 继续展示其余会议，并把该目录标记为不可读，提供查看原始路径的入口。

#### Scenario: 单个目录损坏不影响整体

- **WHEN** 根目录下有一个目录的 `transcript.json` 内容损坏
- **THEN** 其余会议正常展示，损坏目录在列表中标记为不可读且详情页说明原因
