# Android v0.5.4 设计方向

参考基准是独立的 `tancheng33/tingo` main（`f0c08a2`）；本项目在 `develop` 上独立实现，不合并参考仓库代码。所有已选功能完成后进行首次验收。

## 平台与入门

- 应用名为「听过 · Tingo」，应用 ID 为 `io.github.zdfb.tingo`，最低 Android 10；版本号独立使用 0.5.4。旧应用数据不自动删除或迁移。
- APK 不内置模型。首次引导展示 Paraformer 及下载大小，用户确认后下载；移动网络需确认流量。下载支持进度、断点续传和完整性校验。模型就绪前不开始录音。
- 本轮仅接入 Paraformer。SenseVoice、Fun-ASR-Nano 暂缓；正式签名密钥在发布前决定。

## 界面与录音

- 以参考版桌面界面的色彩、信息层次和控件为视觉基准，按手机屏幕重新排版；手机用底部导航，宽屏用侧栏。
- 默认录麦克风，系统声音按需授权；实时工作台展示整场文字、临时说话人和重点标记，两路音频都可参与实时转写。临时编号可能在最终转写后变化，界面应明确提示。
- 标记保留到会议详情并可跳转音频；生成纪要时可选择是否纳入，默认纳入。锁屏和后台使用前台服务；异常中断时尽量保存已录内容并在重开后提示恢复处理。
- 结束后可自动转写和生成纪要；设置页控制默认值，单场会议可临时调整。

## 会议、导出与服务

- 只删录音进入可恢复回收站，默认保留 30 天，可恢复或提前彻底删除；保留期间占用空间。PDF 补齐鱼骨图与排版。
- 会议库存应用私有目录，提供整库备份与恢复。热词用于纪要和术语管理，不自动改写转写原文。
- 纪要服务支持预设及用户填写的公网 HTTPS 兼容地址；应用更新入口跳转 GitHub Releases。Obsidian 与群机器人推送本轮不做。
- 现有 ARM64 与 x86_64 支持保留，正式包按架构分发。先设计和开发，规格文档与双轴代码审查随后补充。
