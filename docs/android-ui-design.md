# 听过 Android 界面设计

## 方向

会议工作台：优先显示用户当前正在处理的内容。视觉参考独立参考仓库 v0.5.4 桌面版，保留听过蓝、系统字体以及跟随系统的明暗主题。手机使用底部导航，宽屏保留现有自适应导航。

## 共同规则

- 色彩使用 `TingoTheme.colors`，尺寸与圆角使用 `TingoDimens`；强调色只用于主要操作、当前选择和状态。
- 操作保持足够的触摸范围；删除或放弃不可恢复的内容前要求确认。
- 页面分别处理加载、空、错误和有内容状态；不使用虚构的指标或用户数据。
- 文字、操作与真实状态绑定；在识别不完整、权限不足或操作失败时显示原因。
- 尽量用留白和分隔线组织信息，避免嵌套卡片；尊重系统字体缩放和深色模式。

## 页面

1. **录音**：录音前提供来源和处理选项；录音中使用固定状态、全文滚动区和固定操作区。说话人编号明确标注为临时结果。
2. **会议记录**：搜索和筛选在列表之前；会议标题、时间和处理状态构成主层级，归档及回收站保持可达。
3. **会议详情**：纪要、转写和录音按任务分区；来源时间可回听，重点标记与导出保持可用。
4. **设置**：按模型、录音、数据和关于分组，当前配置与失败原因可见。
5. **新手引导**：保留模型下载、权限、纪要服务和示例会议步骤；下载量与移动网络提示在确认前可见。
